# Cribra Core v0.7.0 — Release Preparation

> **Historical preparation record.** This document captures the v0.7.0 candidate
> stage. Its native ABI statements (protocol 0.1.0) are superseded by the
> published v0.7.2 contract, which uses ABI **0.3.0**. See
> [Interoperability](INTEROP.md#17-abi-versioning) and the checked-in
> [header](../include/cribra.h) for the current contract.

Date: 2026-10-15

Status: RELEASE CANDIDATE — NOT PUBLISHED

## Scope

Cribra v0.7 consolidates the existing synchronous, local-first Rust
engine through configurable build profiles, incremental performance
optimizations, and integration-quality qualification.

The release does not introduce a new detection engine or change the
authoritative scanning semantics.

## Core profiles

| Profile | Configuration | Capabilities |
| --- | --- | --- |
| Core | `--no-default-features` | Scanning, reporting, streaming, incremental scanning |
| Flow | Default (`transform`) | Core plus transformations |
| Fuse | `--all-features` | Flow plus parallel execution and Serde |

These are documented combinations of existing Cargo features,
not additional Cargo features.

## Performance

Incremental edit measurements versus the v0.6 baseline:

| Workload | Change |
| --- | ---: |
| `dense-8-64k` | -46.62% |
| `mixed-64k` | -8.76% |
| `sparse-64-64k` | -2.02% |
| `sparse-4-1k` | +3.60% |

Measurements were collected before integration with configurable
profiles. The combined implementation passed regression tests but
was not independently rebenchmarked.

These results are local measurements, not cross-platform guarantees.
The small-input regression is explicitly retained.

See `docs/PERFORMANCE.md`.

## Adapter compatibility

Adapter releases remain independently versioned.

- Rust core: 0.7.0.
- WASM adapter: 0.4.7 source version unchanged.
- CLI adapter: 0.4.4 source version unchanged.
- C adapter: 0.3.0 source version unchanged.
- Native C ABI protocol: 0.1.0 unchanged.

The workspace CLI and WASM dependency requirements have been updated
to core `^0.7` for source compatibility with this release candidate.

This does not retroactively change previously published adapter
artifacts or imply new adapter releases.

WASM supports Core and Flow configurations. Flow remains the default
distribution profile. WASM Fuse is unsupported.

Rust streaming and incremental APIs are not exposed through the
existing WASM, CLI or C adapter contracts.

## Integration decisions

- No generalized capability manifest is required for v0.7.
- Precompiled WASM Flow distribution is approved in principle but
  remains a separate, deferred adapter release activity.
- C ABI ownership, error handling and compatibility were qualified.
- No ABI signatures, symbols or data layouts were changed.

See `docs/0.7-adapter-boundary-audit.md`.

- Local Core, Flow and Fuse compilation and regression checks
  after updating the workspace to core 0.7.0.
- Existing C ABI conformance and native C consumer smoke checks.
- Existing WASM Core/Flow runtime qualification.

Pending for final release authorization:

## Publication boundary

The core release tag is `v0.7.0`.

Pushing this tag triggers the automated release workflow, including
publication of the core crate to crates.io and creation of a GitHub
Release after validation.

Do not create or push the release tag during preparation.

No CLI, WASM or C adapter release is implied by the core tag.
