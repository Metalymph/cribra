# Flow artifact provenance

This record pins the production Flow WebAssembly artifact used by the
qualification extension. `artifact.lock.json` is the machine-readable source of
truth; `npm run build` verifies the generated artifact against it.

## Source

| Field | Value |
| --- | --- |
| Repository | `Metalymph/cribra` |
| Baseline commit | `33d0c01947abc2488cf406aba24e8ba84b4834e7` |
| Adapter crate | `cribra-wasm` 0.4.7 |
| Core crate | `cribra` 0.7.2 |
| Cargo features | `transform` (Flow profile) |
| wasm target | `wasm32-unknown-unknown` |
| Build profile | Cargo `--release --locked` |

The build deliberately never reads the WASM or glue from the generated
`packages/cribra/src/wasm` and `packages/cribra/dist` directories. Both can
contain a different build.

## Reproduce

```sh
cd packages/cribra-guard
npm install
npm run build
```

The build runs:

```sh
cargo build -p cribra-wasm --target wasm32-unknown-unknown --release --locked
wasm-bindgen --target web --out-dir .build/raw --out-name cribra \
  target/wasm32-unknown-unknown/release/cribra_wasm.wasm
wasm-opt -Oz .build/raw/cribra_bg.wasm -o .build/flow/cribra_bg.wasm
```

A second identical build produced the same WASM, glue, and service-worker
hashes. The extension embeds the WASM size and SHA-256 at build time and checks
the fetched extension asset before initialization.

## Intentional updates

Only update the lock after an intentional artifact change:

```sh
node scripts/build.mjs --write-lock
```

Then re-run `npm run qualify` and record the new measurements. Do not accept a
silent artifact change.
