# Cribra for React Native 0.86

This private distribution uses the same scanner, C ABI and serial worker as
the React Native 0.88 package. Its public API supports scans, batch scans,
Redact and Template. The Android bridge ships Codegen 0.86.3 output because
a purely C++ dependency has no Gradle target on which to run library Codegen.
iOS uses the consumer's CocoaPods Codegen step. Install one variant per app.

## Build and pack

Use Rust 1.100.0, cargo-ndk 4.1.2, Android NDK 27.1.12297006, Xcode
27.2 (27B52) and Node 26.13.1. Install the seven Rust targets listed by
`scripts/build-native.sh` or selected by cargo-ndk. Install React Native and
Codegen 0.86.3 using a frozen consumer lockfile. From a clean Cribra checkout:

```sh
IPHONEOS_DEPLOYMENT_TARGET=17.0 bash packages/cribra-react-native/scripts/build-native.sh all
node packages/cribra-react-native/scripts/pack-rn86.mjs /path/to/output /path/to/node_modules/react-native
```

Compare the resulting archive and checksums against the release manifest.
The upstream commit and Cargo.lock checksum identify the source. Archive
file order, modes, ownership and timestamps are normalized. Reverify
checksums from a new checkout before promoting a new release.

The projection lives in the upstream pack script. Changes to the RN 0.88
facade or spec can require changes to the projection. Qualify each version
with Android and iOS build and runtime tests after regenerating the package.
